# Civic Vote 项目使用说明书

## 项目简介

Civic Vote 是部署在 Solana devnet 的无管理员治理实验：标准 SPL Token 总量固定为 1,000,000（6 decimals），初始化时一次性进入社区 treasury 并永久撤销 mint authority。任何钱包可首次加入并获得 1,000 Token 的 365 天线性释放额度，每 24 小时领取；任何钱包可创建 7 天赞成/反对提案、投入 Token 投票，结算后投票 Token 只能回到 treasury。

## 架构与目录

- `program/src/lib.rs`：Pinocchio 链上程序与单元测试。
- `lib/vote.ts`：ABI 显式编码、状态解析和 PDA 推导。
- `app/`：Next.js App Router playground，覆盖 Join、Claim、CreateProposal、Vote、Settle。
- `scripts/initialize.ts`：一次性创建标准 SPL Mint、treasury 并初始化协议。
- `scripts/deploy.sh`：SBF 构建与 devnet 部署。
- `docs/ABI.md`：完整二进制接口。

## 环境与启动

要求 Rust、Solana CLI 4.x、`cargo-build-sbf`、Node.js 22、pnpm 11 和 Vercel CLI。执行：

```bash
pnpm install
pnpm run dev
```

钱包切换到 Devnet，访问 `http://localhost:3000`。Program ID 为 `BvTUyzWLwyoX47bXndjupDzzbtHBFGNWUsZhwsFNkTXe`；Config PDA 与 Token Mint、Treasury 地址见下方“已部署地址”。

## 页面操作

1. 连接钱包，点击“加入社区”；重复加入会因 PDA 已初始化失败。
2. 加入后等待释放，点击 Claim。首次也必须已有非零释放量；之后间隔至少 24 小时。
3. 在“投票内容”中输入 1–160 UTF-8 bytes 的明确表决事项，点击“支付 10 CVOTE 并创建”；程序验证创建者 Token Account 后，将 10 CVOTE 转回 community treasury。内容、截止时间和票数均保存在链上。
4. 页面自动读取并展示全部 Proposal，PDA 地址作为技术细节隐藏。每张卡显示投票状态、截止时间、赞成票和反对票；输入 Token 数量并投赞成或反对，同一钱包不能换边，可向原方向追加。
5. 截止前结算按钮不可用；7 天到期后显示“已到期 · 可结算回收”，任何人可结算，vault 全额回到社区 treasury，投票者不可取回。

连接钱包后，“加入社区”会读取 Member PDA 并显示“已加入”状态；Claim 卡片按当前链上时间展示累计已释放但尚未领取的 Token 数量。

## 命令、构建与部署

```bash
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
NO_DNA=1 cargo build-sbf
./scripts/deploy.sh vote-program-keypair.json
pnpm run typecheck
pnpm run build
pnpm run initialize
```

部署只允许 devnet。`vote-program-keypair.json` 决定 Program ID，已由 `.gitignore` 排除，禁止提交或分享。初始化脚本默认读取 Solana CLI 当前钱包；可通过 `SOLANA_KEYPAIR` 指向另一份本地文件，但不得把私钥写入仓库。

## 安全说明与排错

链上校验 signer、账户 owner/长度/discriminator、PDA、Token Program/System Program、mint 与 vault 关系；金额使用 checked arithmetic。无管理员意味着参数不可升级、提案无需许可，且任何人可占用剩余社区名额；这是明确的产品特性，也意味着该演示不适合直接承载真实价值。

- `InvalidPda`：客户端使用了错误 wallet、proposal 或 nonce 推导。
- `TooEarly`：24 小时 Claim 间隔或 7 天提案期尚未结束。
- `AllocationExhausted`：1,000,000 总供应已全部预留。
- `VotingClosed`：提案过期或已结算。
- 余额不足：从 devnet faucet 获取测试 SOL；不要使用主网资金。
