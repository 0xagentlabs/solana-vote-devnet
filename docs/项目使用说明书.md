# Civic Vote 项目使用说明书

## 项目简介

Civic Vote 是部署在 Solana devnet 的无管理员治理实验：标准 SPL Token 总量固定为 1,000,000（6 decimals），初始化时一次性进入社区 treasury 并永久撤销 mint authority。任何钱包可首次加入并获得 1,000 Token 的 365 天线性释放额度，每 24 小时领取；任何钱包可创建 7 天赞成/反对提案、投入 Token 投票。创建费用与结算回库的投票 Token 会作为“治理权回流奖励”平均记给当时所有成员，可再次用于投票；CVOTE 不代表资产收益或现金分红。

## 架构与目录

- `program/src/lib.rs`：Pinocchio 链上程序与单元测试。
- `lib/vote.ts`：ABI 显式编码、状态解析和 PDA 推导。
- `app/`：Next.js App Router playground，覆盖 Join、Claim、ClaimReward、CreateProposal、Vote、Settle。
- `scripts/initialize.ts`：一次性创建标准 SPL Mint、treasury 并初始化协议。
- `scripts/initialize-rewards.ts`：程序升级后一次性初始化 RewardState。
- `scripts/deploy.sh`：SBF 构建与 devnet 部署。
- `docs/ABI.md`：完整二进制接口。

## 页面操作

1. 连接钱包，点击“加入社区”；重复加入会因 PDA 已初始化失败。
2. 在“我的 CVOTE”卡片查看当前钱包余额。加入后，线性释放与治理权回流两个 Claim 集中显示；任一项目可领取数量为 0 时，该项目不会展示。线性释放首次也必须已有非零释放量，之后间隔至少 24 小时。
3. 提案费用和结算回收 Token 会平均记给回收发生时的全部成员；新成员不能追领加入前的奖励，未领取奖励持续累计。
4. 在“投票内容”中输入 1–160 UTF-8 bytes 的明确表决事项，点击“支付 10 CVOTE 并创建”；程序验证创建者 Token Account 后，将 10 CVOTE 转回 community treasury 并计入治理权回流奖励。内容、截止时间和票数均保存在链上。
5. 页面自动读取并展示全部 Proposal，PDA 地址作为技术细节隐藏。每张卡显示投票状态、截止时间、赞成票和反对票；输入 Token 数量并投赞成或反对。每次投票最少 `0.01 CVOTE`（`10_000` base units），同一钱包不能换边，可向原方向追加。
6. 截止前结算按钮不可用；7 天到期后显示“已到期 · 可结算回收”，任何人可结算，vault 全额回到 community treasury 并平均计入治理权回流奖励，投票者不能按原存入额取回。

连接钱包后，“加入社区”会读取 Member PDA 并显示“已加入”状态。每个成功加入的钱包地址会独立预留 **1,000 CVOTE**，从该地址的链上加入时间起，在 **365 天**内线性释放，平均每天约 `1,000 / 365 = 2.739726 CVOTE`；满 365 天后该地址累计最多可领取 1,000 CVOTE。

“我的 CVOTE”卡片中的线性释放 Claim 只计算当前连接地址，不统计、也不依赖社区已加入的地址数量。显示值为：

```text
当前可领取 = 当前地址截至此刻累计已释放额度 - 当前地址累计已领取额度
```

不同地址的加入时间、释放进度和已领取数量互相独立；其他地址加入或领取不会改变当前地址的线性释放可领取数量。24 小时间隔只限制 Claim 交易频率，不改变线性释放速度；等待期间新增释放会继续累计到下一次可领取余额中。治理权回流奖励是独立余额：每次回库按当时成员数更新全局平均奖励指数，各地址自行领取，不需要链上遍历成员；整数余数留待后续回收继续分配。

## 命令、构建与部署

```bash
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
NO_DNA=1 cargo build-sbf
./scripts/deploy.sh vote-program-keypair.json
pnpm run test:unit
pnpm run typecheck
pnpm run build
pnpm run initialize
pnpm run initialize:rewards
```

部署只允许 devnet。`vote-program-keypair.json` 决定 Program ID，已由 `.gitignore` 排除，禁止提交或分享。初始化脚本默认读取 Solana CLI 当前钱包；可通过 `SOLANA_KEYPAIR` 指向另一份本地文件，但不得把私钥写入仓库。

## 安全说明与排错

链上校验 signer、账户 owner/长度/discriminator、PDA、Token Program/System Program、mint 与 vault 关系；金额使用 checked arithmetic。无管理员意味着参数不可升级、提案无需许可，且任何人可占用剩余社区名额；这是明确的产品特性，也意味着该演示不适合直接承载真实价值。

- `InvalidPda`：客户端使用了错误 wallet、proposal 或 nonce 推导。
- `TooEarly`：24 小时 Claim 间隔或 7 天提案期尚未结束。
- `AllocationExhausted`：1,000,000 总供应已全部预留。
- `InvalidAmount`：当前没有可领取的线性释放额度或治理权回流奖励。
- `VotingClosed`：提案过期或已结算。
- `InvalidAmount`：投票数量低于 0.01 CVOTE，或其他指令的金额不符合协议要求。
- 余额不足：从 devnet faucet 获取测试 SOL；不要使用主网资金。
